📜 Grimório das 100 Magias

1. Aceleração Temporal (Time Rush): O tempo passa 10× mais rápido em INT × 3 m. Dura por 10 Rodadas (para você).

2. Acelerar (Haste): INT criaturas têm sua velocidade de movimento triplicada.

3. Aderir (Adhere): INT objetos tornam-se pegajosos o suficiente para manter um PC preso ao teto. Dura até serem lavados.

4. Alterar Gravidade (Gravity Shift): INT criaturas podem mudar livremente a direção do seu “baixo”.

5. Amizade Animal (Animal Friendship): INT animais obedecem às suas ordens tão bem quanto um cão treinado por 1 Dia.

6. Animar Objeto (Animate Object): INT objetos obedecem às suas ordens. Eles se movem 4,5 m por Rodada.

7. Antropomorfizar (Anthropomorphize): INT animais ganham inteligência humana por 1 Dia.

8. Apreender Magia (Spellseize): Como Reação, copie temporariamente uma magia de nível INT ou inferior para conjurá-la em até 1 Dia.

9. Ar Líquido (Liquid Air): O ar dentro de INT × 3 m torna-se nadável.

10. Arrombar (Knock): INT fechaduras são destrancadas.

11. Atrair (Attract): INT + 1 objetos são fortemente atraídos magneticamente entre si se ficarem a 3 m de distância.

12. Aumentar Gravidade (Increase Gravity): A gravidade dentro de INT × 3 m de você é triplicada.

13. Âncora Taumatúrgica (Thaumaturgic Anchor): Um objeto atrai todas as magias conjuradas a até 36 m por INT Turnos.

14. Balbuciar (Babble): INT Criaturas repetem em voz alta tudo o que você pensa. Fora isso, ficam mudas.

15. Caminhar Pelo Espelho (Mirrorwalk): Um espelho torna-se portal para outro espelho que você tocou hoje.

16. Carruagem Fantasma (Phantom Coach): Uma carruagem recolhe INT criaturas ao ar livre e as deixa em um hexágono adjacente aleatório.

17. Catarina (Catherine): Uma mulher de vestido azul aparece por INT Horas. Ela obedece a pedidos educados e seguros.

18. Cavaleiro do Caracol (Snail Knight): Após 10 minutos, um cavaleiro em um caracol gigante surge. Pode ajudá-lo por INT dias se o julgar digno. O caracol anda apenas em passo normal.

19. Classificar (Sort): Itens se organizam segundo INT categorias visuais definidas por você.

20. Comandar (Command): Uma criatura obedece a um único comando de INT palavras que não a prejudique.

21. Compreender (Comprehend): Você é fluente em todas as línguas por INT Horas.

22. Confundir (Befuddle): Uma criatura não consegue formar memórias de curto prazo por INT Turnos.

23. Conjurar Cubo (Summon Cube): Conjure ou bana um cubo de terra de 1,5 m, 5 vezes por Rodada, por INT Rodadas. Cubos devem estar conectados ao solo ou entre si.

24. Conjurar Ídolo (Summon Idol): Uma estátua de pedra de até INT × 3 m emerge do chão.

25. Controlar Clima (Control Weather): Você controla o clima do seu hexágono por INT Horas.

26. Controlar Plantas (Control Plants): Plantas dentro de INT × 3 m obedecem a você. Elas se movem 1,5 m por Rodada.

27. Desfazer (Unravel): Como Reação, anule uma magia de nível INT ou inferior.

28. Deslocar (Displace): Um objeto parece estar até INT × 3 m distante de sua posição real.

29. Desmontar (Disassemble): INT partes do corpo podem ser destacadas à vontade. Você ainda as controla. Dura até serem recolocadas.

30. Detectar Magia (Detect Magic): Tudo que for mágico dentro da linha de visão brilha e revela suas propriedades quando solicitado. Dura 1 Dia ou INT solicitações.

31. Disfarçar (Disguise): Você altera a aparência de INT humanoides, desde que permaneçam humanoides. Dura até que falem.

32. Dobrar o Destino (Bend Fate): Role INT + 1d20. Sempre que qualquer criatura visível fizer um teste, use e descarte um dos resultados até que todos sejam usados.

33. Duplicar (Duplicate): Cria INT cópias frágeis de porcelana de itens visíveis.

34. Elasticidade (Elasticity): Seu corpo pode se esticar até INT × 3 m.

35. Elo Invisível (Invisible Tether): INT objetos a até 3 m uns dos outros não podem ser separados por mais de 3 m.

36. Embaralhar (Shuffle): INT criaturas trocam de lugar aleatoriamente.

37. Empurrar (Push): Um objeto é empurrado para longe com a força de INT homens por 1 Rodada.

38. Encantar (Charm): INT humanoides acreditam ser amigos próximos de você até prova do contrário.

39. Enxame (Swarm): Você se torna um enxame por INT Turnos, sofrendo dano apenas de efeitos de área.

40. Erguer Mortos (Raise Dead): INT esqueletos desarmados se erguem para servi-lo.

41. Escalada Aracnídea (Spider Climb): Você escala superfícies como uma aranha por INT Turnos.

42. Esculpir Elementos (Sculpt Elements): Material inanimado age como argila por INT Turnos.

43. Esfera Noturna (Night Sphere): Uma esfera de escuridão total com INT × 12 m de largura aparece.

44. Espetáculo (Spectacle): Uma ilusão claramente irreal surge por INT Dias, com som e movimento completos, até o tamanho de um palácio.

45. Falar com os Mortos (Speak with Dead): O espírito de um cadáver tocado responde INT perguntas, se puder.

46. Farejar (Sniff): Uma criatura sente cheiros até 36 m por INT Turnos.

47. Flutuar (Hover): INT objetos flutuam 0,6 m acima do solo, sem atrito, suportando até INT pessoas.

48. Fobia (Phobia): INT criaturas ficam aterrorizadas por um objeto.

49. Forma Bestial (Beast Form): Você e seus pertences se transformam em um animal por INT Dias.

50. Forma de Fumaça (Smoke Form): Seu corpo e equipamentos tornam-se fumaça viva por INT Turnos.

51. Forma de Gosma (Ooze Form): Seu corpo e equipamentos tornam-se gosma viva por INT Turnos.

52. Fosso (Pit): Um fosso de 3 m de largura e INT × 3 m de profundidade se abre.

53. Ganância (Greed): INT criaturas ficam obcecadas em possuir um item visível.

54. Hipnotizar (Hypnotize): Uma criatura entra em transe e responde INT perguntas de “sim” ou “não”.

55. Ilusão Auditiva (Auditory Illusion): Você cria sons ilusórios que parecem vir de INT direções à sua escolha.

56. Ilusão Visual (Visual Illusion): Cria INT ilusões imóveis e silenciosas até serem tocadas.

57. Imagem Espelhada (Mirror Image): INT cópias ilusórias suas aparecem sob seu controle.

58. Lentidão Temporal (Time Slow): O tempo passa 10× mais lento em INT × 3 m por 10 Rodadas (para você).

59. Ler Mentes (Read Mind): Você ouve pensamentos superficiais por INT Turnos.

60. Loucura das Bolinhas (Marble Madness): Seus bolsos se enchem de bolinhas a cada Rodada por INT Rodadas.

61. Mansão (Manse): Uma casa mobiliada com INT cômodos surge por 1 Dia. Não possui comida nem equipamentos e não é refúgio seguro.

62. Marca do Mago (Wizard Mark): Você produz tinta invisível aos outros por INT Horas, visível a qualquer distância.

63. Mascarada (Masquerade): Criaturas dentro de INT × 3 m são compelidas a dançar.

64. Matagal (Thicket): Vegetação densa de até INT × 12 m cresce em 1 Rodada.

65. Miniaturizar (Miniaturize): Você e INT criaturas tocadas tornam-se do tamanho de um rato.

66. Múltiplos Braços (Multiarm): Você ganha INT braços adicionais.

67. Muralha Elemental (Elemental Wall): Cria uma parede de gelo ou fogo com INT × 12 m de comprimento, 1,5 m de largura e 3 m de altura, podendo ser curvada livremente.

68. Nuvem de Névoa (Fog Cloud): Névoa se espalha em um raio de INT × 3 m. Dissipa-se em 1 Turno.

69. Objetificar (Objectify): INT criaturas voluntárias tornam-se objetos inanimados enquanto desejarem, mantendo visão e audição.

70. Ódio (Hatred): INT criaturas passam a se atacar por 1 Turno ou até que uma morra.

71. Olho Arcano (Arcane Eye): Você cria um olho mágico que voa sob seu controle por INT Turnos. Você pode enxergar através dele tão bem quanto com seus olhos normais.

72. Ouvir Sussurros (Hear Whispers): Uma criatura ouve todos os sons até 36 m de distância por INT Turnos.

73. Pacificação (Pacify): INT criaturas passam a odiar violência, a menos que sejam atacadas.

74. Perscrutar (Scry): Você compartilha a visão de uma criatura tocada hoje por INT Turnos.

75. Prisão Astral (Astral Prison): Um objeto é congelado no tempo e no espaço dentro de uma concha cristalina invulnerável por INT Turnos.

76. Proteção (Ward): Um círculo de prata de 12 m impede INT tipos de coisas enquanto você estiver dentro.

77. Psicometria (Psychometry): O GM responde INT perguntas de “sim” ou “não” sobre um objeto.

78. Puxar (Pull): Um objeto é puxado em sua direção com a força de INT homens por 1 Rodada.

79. Redemoinho (Whirlwind): Cria um vórtice de ar de INT × 3 m que desvia projéteis.

80. Repelir (Repel): INT + 1 objetos se repelem magneticamente a 3 m de distância.

81. Ressurgência (Upwell): Uma fonte jorra ~28 m³ de água por Turno durante INT Turnos.

82. Salto (Leap): Você pode saltar até INT × 3 m.

83. Salto Temporal (Time Jump): Um objeto salta INT Turnos no futuro e destrói a matéria ao retornar.

84. Sentir Verdade (Truth Sense): Você detecta mentiras por INT Horas.

85. Silêncio (Silence): Todo som é abafado em 3 m por INT Turnos.

86. Sono (Sleep): INT criaturas adormecem.

87. Supressor Mágico (Magic Suppressor): Toda magia é anulada dentro de INT × 3 m de você.

88. Surrupiar (Filch): INT itens visíveis se teleportam para suas mãos.

89. Surto Primeval (Primeval Surge): Um objeto cresce até o tamanho de um elefante por INT Turnos. Criaturas ficam enfurecidas.

90. Telecinese (Telekinesis): Manipule um item por vez a até 3 m por INT Turnos.

91. Telepatia (Telepathy): Projete pensamentos para uma mente em INT hexágonos.

92. Teleporte (Teleport): Um objeto se teleporta até INT × 12 m.

93. Terremoto (Earthquake): O chão treme violentamente por INT Rodadas.

94. Teia (Web): Dispare INT × 12 m de teia pegajosa até ser queimada.

95. Toque Gélido (Icy Touch): Uma camada de gelo se espalha em um raio de INT × 3 m.

96. Trancar (Lock): Uma porta não pode ser aberta por meios mundanos por INT Turnos.

97. Troca de Corpos (Body Swap): Você troca de corpo com uma criatura tocada por INT Turnos. Se um corpo morrer, o outro também morre.

99. Visão (Vision): Uma ilusão completa perceptível por apenas uma criatura por INT Turnos.
